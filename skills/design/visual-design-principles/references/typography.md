# 字体与排版

依据：原书第 9—12、15 章及第 14 章答案。中文与 UI 注意事项为转用建议。

## 从文字角色出发

先看现有设计系统和可用字体。标题、正文、辅助说明、标签、数字及行动各需要什么表现，再选择字体和字重。不要先选一串字体再给内容找用途。

用真实中文、英文、数字、标点和长文本检查，不只看英文示例。相同标称字号不保证相同视觉大小，x-height、字面大小、字宽和笔画密度都会影响效果。

## 协调、冲突和对比

- 协调：字形和风格保持一致，可适合长文、正式文件或安静界面。它不是失败。
- 冲突：看起来像要保持相同，又在某些细节上不一致；也可能是两个角色争夺同一层级。
- 对比：有目的的差异，帮助辨认层级与角色。

搭配不舒服时，不只列出字体差异，也检查共同点：是否同样细、同样倾斜、同样装饰性强？这些共同点是否让不同角色难以区分？

不要为了构造对比强制增加第二种字体。字重范围充足的一个家族往往已经够用。

## 六类字体如何帮助选择

这里是原书对拉丁字体的教学分类，不是全部字体的完备分类，也不能直接套成中文字体分类。

| 类别 | 观察特征 | 对选择的意义 |
|---|---|---|
| 旧式体 Oldstyle | 倾斜的强调线，带过渡的衬线，笔画粗细变化较温和 | 可作为长文候选；仍需按尺寸与媒介检查 |
| 现代体 Modern | 垂直强调线、细而平的衬线、明显粗细变化 | 大标题可形成鲜明形态，小尺寸需检查细笔画 |
| 粗衬线体 Slab serif | 较厚衬线，通常粗细变化较小 | 可产生扎实的文字色块；正文版本不必很粗 |
| 无衬线体 Sans serif | 无衬线，多数笔画变化较小，也存在例外 | 看具体家族的字形与字重，不凭类别判断搭配 |
| 手写体 Script | 书写感、连笔或非连笔、可能倾斜 | 适合有限的表达性短文，慎用于长文与关键小字 |
| 装饰体 Decorative | 独特形态强，显著影响气质 | 用在承担表达的有限角色；验证识别性 |

原书建议初学者避免同类不同家族的相似字体混用，并在文中展示例外。实用结论是避免难以解释的近似，不能转成“同一页面不准有两个无衬线字体”的通用禁令。多语言回退字体尤其不能这样判断。

## 六种对比及其使用

| 维度 | 可执行判断 | 常见误用 |
|---|---|---|
| 大小 | 在实际尺寸下主次能否区分；能否缩小辅助项而非继续放大标题 | 所有文字都大；只在放大预览时看得出差异 |
| 粗细 | 真实可用字重是否形成需要的强调 | 声明了不存在的字重；小而极粗副标题抢过大而细标题 |
| 结构 | 笔画变化、衬线、比例是否真的不同 | 仅凭两个字体名字不同就认为有对比 |
| 形状 | 直立与斜体、大小写是否有角色含义 | 两种飘逸字体混用；把所有内容改全大写 |
| 方向 | 长横标题与纵向内容列能否形成清楚关系 | 无理由旋转正文、把斜字塞进角落 |
| 颜色与文字密度 | 字重、字距、行距形成的深浅是否支持组织 | 只改色相；用过淡文字获得“轻盈”感 |

需要较强区分时可以结合多个维度，但要让它们支持同一角色关系。不是每个标题都需要同时变色、放大、加粗、旋转。

## 排版细节

- 标题换行按语义组织，再检查形状。不要为了凑齐一条边拆开品牌名、数字单位或不该断开的短语。
- 标题字号较大时检查字偶间距；整体 tracking 与字偶 kerning 不是同一个调整。先使用字体和排版引擎提供的能力，再做必要的人工修正。
- 正文行长、行距和字号一起看。行距过大也会拆散段落；不要把增加行距当成唯一可读性修正。
- 段落间距和首行缩进都能标识新段，按语言、文体与既有样式选择。原书的英文 1 em 缩进不是中文正文统一标准。
- 列表换行与正文起点对齐，标记属于条目，不独立成列。源码中的 Markdown 连字符会渲染为项目符号，不属于书中批评的纸面连字符列表。
- 检查孤立的短末行、被拆散的标题、跨页或跨列悬挂的单行。先调整容器或排版规则；无文案修改权限时不要为了排版删改内容。
- 采用符合语言与产品规范的引号、撇号、连接号和破折号。代码、命令、标识符和用户原始输入不做智能标点替换。
- URL、邮箱、号码的可见文本和实际值均须保真，不为“更易读”随意更改大小写或字符。不能从网址某一部分的规则推导邮箱、路径和令牌的规则。
- 正文强调可用字重等方式；链接下划线具有交互含义，不能套用印刷文字的去下划线建议。
- 框中文字检查四周视觉空间；有上下伸部的字体或图标可能需要光学调整，不等于四边数值必须完全相同。

## 中文和混排的转用

中文没有拉丁字母式大小写。不要用拉大汉字间距来模拟英文大写标题的默认风格，也不默认把宋体与黑体称作书中的旧式体与无衬线体等价物。

检查中文标点、英文基线、数字高度、字重匹配与回退字体。必要时分别设置文字角色，保留整体层级。数字表格需要便于纵向比较；正文数字则应融入句子，不要无意变成视觉焦点。

字体选择应服从语言覆盖、授权、加载环境和现有产品风格。原书字体清单用于观察形态，不是必须下载的依赖清单。
