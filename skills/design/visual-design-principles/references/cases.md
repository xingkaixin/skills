# 案例决策：学关系，不抄坐标

以下是对原书案例的重新分析。定位使用 EPUB 内的图像文件名；未附原图，不依赖用户机器上的原书路径。需要精确复核原图时请查原书。UI 对应项是转用建议。

## 狗狗寄养广告：共同边界比换一种对齐更重要

出处：第 3 章“到处看看”，`Image00082.jpg`、`Image00083.jpg`。

原稿已有品牌说明与联系信息分组，但居中、左对齐与右对齐彼此缺少关联，几个小插图又散在边角。问题并不只是文字采用居中。

改稿把服务说明与联系信息收在同一右边界，右侧狗狗放大，横向品牌标题与竖向插画共同组织画面。两组文字通过留白分开，又通过共同边界联系。品牌名更宽，不能误读为每一行文字包括品牌名都精确压在同一右边界；插画本身也不是直边照片。

可迁移的判断：

- 先连接两个文字组，而不是分别让它们内部整齐。
- 插画应参与主结构，而不是填角落。
- 保留一个主要品牌焦点，联系信息可读即可；若任务变为即时预约，再重新评估行动层级。

不应推导：右对齐永远更好、电话不能突出、插画永远放右侧、所有边界必须重合。

UI 转用：详情页标题、说明与底部操作如果各有独立容器内边距，先建立共同列边。不要只给它们相同的 `text-align`。

## 菜单：先能找到菜，再让价格可比较

出处：第 2 章，`Image00032.jpg`—`Image00035.jpg`；第 14 章 Gertrude’s Piano Bar 的说明。

原稿把菜名、描述、价格和分类挤成连续文字。改稿先区分分类和菜品，再区分菜名与说明，最终让价格有稳定边界。

关键是同时维护两种关系：价格属于对应菜品，价格之间又可比较。横向分开价格时不能让行的所属关系模糊。菜名与说明的组内距离要小于菜品之间距离。

不应推导：每项都要包卡片，或全部文字都必须沿同一左边界。

UI 转用：订单、费用清单、规格表中的标签与数值，可以使用不同对齐方式，但必须保持行对应。

## 活动列表：不用读字也能看出有几场活动

出处：第 2 章，`Image00021.jpg`；第 14 章 First Friday Club 的说明。

原稿连续排文，活动日期、名称和介绍不容易归组。改稿为每场建立相同的内部顺序，活动之间留出一致空白；联系信息使用不同关系，避免看成又一场活动。

可迁移的判断：重复模板表达“这些是同类项目”，组间空白表达“这是下一个项目”。缩览时仍能辨认分组是有用的检查。

UI 转用：日程列表、搜索结果或通知流应保留同类信息的顺序；长短文案不能破坏组边界。

## 图文相邻：参差文字边可能削弱图片硬边

出处：第 3 章，`Image00079.jpg`、`Image00080.jpg`（Pie as Art）。

改版把图片放到另一侧，让其明确边缘与文字块的稳定边界形成邻接，同时把数字靠近条目。这样既处理了图文之间零碎空隙，也处理了数字的归属。

不应推导：图片只能在左侧、所有文字都该右对齐，或自然插画必须像矩形照片一样对边。

UI 转用：有明显直边的缩略图与短文字可共享边界和基线；图像裁切与布局一起判断。

## 演讲通知：先确定主题还是讲者更重要

出处：第 4 章，`Image00103.jpg`—`Image00105.jpg`。

原稿元素同样显眼。书中两种改法分别选择讲者与演讲题目为入口，并通过字体、位置与重复的深色色块维护结构。

关键不是记住“标题要最大”，而是先确认读者为什么关心。不能未经任务依据就把其中一个焦点方案宣布为唯一正确。

UI 转用：产品页以产品价值为入口，课程页可能以主题或讲师为入口；按任务决定。

## 同系列宣传材料：重复结构可以容纳很大变化

出处：第 8 章，`Image00169.jpg`、`Image00173.jpg`—`Image00176.jpg`、`Image00187.jpg`。

书中的系列作品通过侧边色带、标题位置、字体与标识形成识别，各期图片和细节仍可明显不同。重复承担的是系列身份，不是消灭变化。

UI 转用：共享导航、类型层级和关键间距，允许不同页面根据内容采用不同布局。不要强行把所有页面做成同一种卡片阵列。

## 牙科广告：删除填空插图不等于去掉所有图像

出处：第 8 章，`Image00205.jpg`—`Image00207.jpg`；第 14 章 Dentist 的说明。

原稿含多个随意小图，正文与照片的关系松散。改稿保留主要人物照片，去掉缺少作用的小图，并调整文字、图片和深色色块之间的关系。

有效改动来自减少无关元素和整理空白。分隔色带在改稿中仍可有作用，所以这不是“装饰线全删”的案例。

UI 转用：删除无信息意义的图标或标签，但保留帮助识别、状态判断与操作的图形。

## 字体焦点竞争：大而细和小而粗都想主导

出处：第 12 章测验 #8，`Image00326.jpg`；第 14 章 Funny Farm 的答案。

一项字号较大却较细，另一项较小却粗重且大写。两项各用一种方式争取注意力。应先选主导项，再让大小与重量支持它。

不应推导：页面不能同时出现大标题和粗按钮。若层级清楚、作用域不同，二者可以共存。判断实际竞争，不数粗体个数。

UI 转用：在标题、指标、告警与按钮之间检查相对视觉重量，不能只拿字号表证明层级清楚。

## 对比练习：别只把差异做得更多

出处：第 10—12 章，`Image00282.jpg`—`Image00285.jpg`、`Image00298.jpg`—`Image00299.jpg`。

衬线与无衬线虽然结构不同，但相同大小与重量仍可能使区别不够明确；两种飘逸文字即使字体名称不同，也可能产生近似冲突。改法是选择真正支持角色区分的结构、形状、大小与粗细组合。

UI 转用：可以保留单一家族，用实际存在的字重建立区分。不是要求更多字体、更多颜色和更多强调同时上场。
