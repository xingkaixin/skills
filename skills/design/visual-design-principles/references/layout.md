# 布局判断：从关系到位置

依据：原书第 1—6、13 章。下面的判断方法是转述与操作化，不是要求复刻书中某一种风格。

## 先确定阅读任务

同一组内容可以有不同焦点。演讲海报可以以讲者为入口，也可以以主题为入口；选择取决于受众为何会来。寄养机构宣传卡可以先建立品牌认知，预约界面则可能以完成预约为重点。

先检查实际任务，再定视觉优先级。不要因为出现电话就认定电话必须第二大，也不要因为有 logo 就让它最大。对长文、设置页、数据表，稳定查找可能比单一强烈中心点更重要。

## 亲密性：视觉分组必须忠于语义

先在内容上分组，再移动元素。只因元素形状相似、长度相近或某处有空位而归组，会制造错误关系。

| 观察到的症状 | 需要判断的关系 | 优先改动 |
|---|---|---|
| 标题像夹在两段之间 | 标题属于上文还是下文 | 缩小它与所属正文的距离，增加另一侧距离 |
| 图标、数字像独立一列 | 标记与哪个条目对应 | 缩小标记到文本的距离，保持跨条目的分隔 |
| 所有行等距，无法区分事件 | 哪些行属于同一个事件 | 组内紧密，事件之间有更明显且一致的间距 |
| 地址、电话散在四角 | 是否同属联系信息 | 集中为一个逻辑区域，再处理组内次序 |
| 看起来像同组却语义无关 | 是否误用了邻近关系 | 拉开，或调整顺序使其靠近真实所属项 |
| 内容拥挤但仍有零碎空隙 | 空间是否截留在组内 | 收回无用的组内空隙，把空间留给组间 |

间距差异应足以表达关系，不使用固定倍数作为普遍法则。相等间距通常暗示同级关系；只有语义同级时才让间距相等。不能把“组内紧密”理解成挤压可读性或操作空间。

缩小画面，使文字不可逐字阅读，检查还能否看出真实分组。书中建议通过视线停顿数识别碎片，但提到的约 3—5 项是小版面的启发，不是仪表盘或长页面的硬上限。

## 对齐：找到跨元素的共同基准

对每个主要元素回答“它与谁的什么边界相连”。候选包括文字起边、文字末边、图片直边、中轴、基线、栏边和跨栏边。

局部的 `text-align` 相同，不代表整页建立了联系。两个文字组即使相距较远，只要共用明确边界，仍可属于一个整体。反之，全部居中但各组中轴不同，仍然分散。

选择对齐的依据：

- 左对齐适合需要稳定起点的连续阅读；也容易连接左侧图片或列边。
- 右对齐可以把短文案的硬边连接到右侧图片，或连接上下相隔的文字组。不要因此把长篇正文也改成右对齐。
- 居中适合明确的中轴构图。检查整个组的中轴、行长变化、行距和上下层级；不以“居中必然业余”作为判断。
- 混合对齐需要可解释的共同基准，例如左对齐标题的右边界与右对齐短文的右边界连接，或不同列服从同一网格。
- 多列允许不同列边和缩进；统一意味着这些边界有结构，不是所有东西都在同一条线。

对齐文本与插画时看可见轮廓，不只看素材矩形。透明边缘、图像留白、圆形、标点和不同字形可能要求少量光学校正。不要把书中狗狗图的自然轮廓描述成像照片一样的笔直边。

先建立稳定规则，再判断有意越界是否有表达作用。“我故意这样做”不足以证明有效；需要从画面中看出它改善了动势、主次或图文联系。小幅随机偏移通常更像误差。

## 留白：看形状、位置和连续性

留白是构图的一部分，不是剩余面积。检查：

- 相关组内部有没有过大的空洞，让它看起来被拆开？
- 不相关组是否被压在一起，而大块无用空间留在别处？
- 图片硬边是否正对文字参差边，夹出形状零碎的空隙？是否能换对齐方式或位置改善？
- 边框是否压缩空间、引导视线或建立必要边界？若没有作用，可去掉；若有作用，就保留并调整。

不能通过统计空白面积判断设计好坏。大面积留白可能是有效对比，也可能让说明与主要行动脱节。先判断关系，再决定增加还是减少。

## 重复：先复用已有规则

优先找页面里已经成立的字体角色、颜色、间距、基线、图形语言，再决定是否强化。重复可以连接物理上分离的组，也可以让多个页面属于同一系列。

重复不等于复制所有外观。同一位置、比例或图形结构，可以允许主题颜色、图片和内容变化。变化需要有稳定部分作参照。

过多强调色、粗体、徽章、边框会削弱主次。检查重复的是信息角色还是无差别装饰。不要为了“符合重复原则”新增没有作用的元素。

## 对比：让重点胜出，而不是让每项都变强

同时看字号、字重、面积、位置、色彩、周围留白、图像细节密度。不能只按字号排序。

一个大而细的标题和一个较小却极粗的副标题可能争夺主导。先决定谁重要，再让多个视觉信号支持同一层级。也可以减弱次要项来建立差异，不一定放大主要项。

大小与字重的变化要在目标尺寸上可辨。书中字号差异示例是对“差别过小”的提醒，不是禁止 UI 使用相邻字号、常规与半粗体。状态、注解等细分角色可以采用克制差异，只要读者能可靠辨认。

明确的第二层级并不自动造成双焦点冲突。主次清楚、阅读路径合理时，品牌与行动都可突出。不要把每个粗体都判为抢戏。

## 选择最小改法

比较“改动前的具体关系”和“改动后应有的关系”。优先调整位置、间距、字重或已有颜色；仅在这些手段不能解决真实问题时重组布局。

完成结构后再决定是否需要风格性装饰。装饰可以承载品牌、情绪、重复与方向，但不能替代清楚的分组和对齐。
