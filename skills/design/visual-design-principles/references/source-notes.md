## 版本

来源：用户提供的《写给大家看的设计书》第 4 版 EPUB。

- 作者：Robin Williams。
- 译者：苏金国、李盼等。

- ISBN：978-7-115-40440-4。

## 哪些是原书原则，哪些是转用

原书依据包括：语义与视觉亲近关系、跨元素的对齐联系、重复带来的统一、对比带来的层级、字体结构与形态、颜色关系，以及根据媒介调整设计。

本 Skill 增加的操作化包括：按任务选择参考文件、保持用户内容与现有系统、用具体对象描述目标关系、检查实际渲染、修正后复查，以及避免把提示词当作完成证据。

本 Skill 的 UI 转用包括：组件角色、输入标签与错误的归属、状态语义、响应式重排、真实字重与回退字体、交互和阅读顺序、必要的行为验证。这些不能归称为书中现成规范。

## 没有照搬的建议

| 原书中的建议或表达 | 本 Skill 的处理 |
|---|---|
| 力劝初学者少用居中、只选一种对齐 | 保留为建立明确关系的启发；同时保留书中的有意居中、混合对齐和越界例外 |
| 不用某些常见字体；同类字体尽量不混搭 | 按实际字形、字重和角色判断，不建立字体黑名单；尊重现有系统与多语言回退 |
| 名片可采用很小的字号，某些场合精美感优先 | 不转成降低关键内容可读性的指令；按受众、尺寸与阅读环境验收 |
| 默认下划线不专业 | 仅用于理解印刷强调方式，不禁止链接下划线或其他有明确作用的线 |
| 英文首段、缩进、标点与大小写规则 | 不机械套用中文，不修改代码、标识符与原始数据 |
| 提升网址、邮箱的字母大小写可读性 | 不擅改地址与实际值，不泛化某部分地址的大小写规则 |
| 屏幕图像 72 ppi、印刷固定分辨率与格式 | 使用实际像素、显示或印刷尺寸及交付方要求，不以元数据证明质量 |
| 特定 CMYK 黑色配方与固定信封尺寸 | 不作为通用生产参数，具体项目具体核对 |
| 旧软件菜单、快捷键、商家和价格 | 未搬入执行步骤；需要时查当前工具与供应商要求 |
| 用不公平的展示让客户选择设计师方案 | 不采用；要求相同展示条件下比较 |
| 多处鼓励大胆、加大对比 | 解释为有目的的明确差异，不要求所有 UI 都醒目，也不排斥安静长文 |

书中存在教学简化、时代背景与个别文字或排版异常。遇到疑点不应把它们升级为硬性工程要求。本 Skill 没有对原书所有技术叙述进行外部事实审校，也不能作为现代无障碍、字体技术或印刷合规手册。

## 如何继续改进

记录真实任务中出现的具体失败，优先修正导致失败的决策步骤。不要因一次失败就增加全局禁令，例如一次图文左对齐失败，不应变成一律右对齐。

使用案例检查推理是否成立，再用成品检查执行是否成立。只有结构校验或纸面走查，不能证明未来的 UI 或图像质量。
