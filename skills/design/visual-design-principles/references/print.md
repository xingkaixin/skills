# 按媒介做取舍

依据：原书第 8、13 章与附录 A、C。这里保留媒介意识，不照搬过时的软件操作、价格、印刷商或固定尺寸。

## 先确定它如何被阅读

| 媒介 | 决定布局前先判断 | 主要取舍 |
|---|---|---|
| 名片 | 代表谁、要保留哪些联络渠道、拿在手中如何读 | 不把它塞成缩小的宣传册；横竖版按内容选择 |
| 海报或传单 | 路过看、近距离看，还是寄给已有兴趣的读者 | 路过看需要迅速辨认重点；近读材料可承载更多细节 |
| 明信片 | 正反面如何分配信息 | 一面集中消息，另一面承接细节；具体按投递与版式约束 |
| 新闻简报或报告 | 多页怎样保持识别并支持持续阅读 | 共享标题、栏边、页码、图注与间距规则，特殊内容可变化 |
| 宣传册 | 折叠与展开时会依次出现什么 | 先做折页模型，按展开顺序安排内容，不只看平铺页面 |
| 品牌套件 | 各件怎样让人识别同一来源 | 重复关键字体、色彩、位置或图形，不必每件完全同版 |
| 简历 | 对方如何接收、查找与阅读 | 专业领域、内容和交付要求决定视觉尺度；不擅改履历 |
| 演示稿 | 投影、远看还是个人屏幕阅读 | 强化远距离可辨的层级；跨页重复服务连续叙事 |

## 密集环境里的对比

广告不仅与自身元素比较，也与周围页面竞争。在周围内容密集时，留白和少量文字可能比更大的标题更突出。不能据此在需要远看时把关键消息缩成小字。

同样，正文页面的“平静”可能是正确选择。不要为了增加回头率而在长文里处处制造焦点。

## 边框、图片和装饰

边框可能建立系列识别、区分版面或服务实际裁切，也可能无谓压缩空间。先判断功能，再决定保留、减轻或删除。

图片应参与文字的边界、方向或主题，不因为角落有空间就塞入剪贴画。可通过裁切、比例、位置和有限重叠改善联系；有信息或品牌意义的图像不得为了整齐而随意裁掉关键部分。

稳定的网格允许跨栏、越界和多样构图。它不是要求整页都变成等大的格子。

## 印刷交付

先确认成品尺寸、出血、安全区、折线与印刷方的文件要求。不要从一本书里的某种信封规格或三折尺寸推断当前项目。

按最终物理尺寸检查文字、细线、反白、色彩和图片有效分辨率。有效分辨率取决于图像像素与实际印刷尺寸；仅修改 DPI 元数据不会创造细节。

色彩空间、ICC 配置、导出格式和黑色处理服从供应商要求。不要把“全部转 CMYK”“必须 TIFF”或某个固定四色黑配方当作普适指令。能打样时检查实物；只检查了屏幕就明确说明尚未打样。

屏幕图像也不以“72 ppi”元数据决定清晰度，应看像素尺寸、实际显示大小和显示环境。

## 公平比较

比较两个版本时保持相同展示比例、背景和清晰度。不能让一个版本有精美样机，而另一个版本模糊歪斜，再把展示差异归为设计优势。

原书第 13 章有通过弄脏对方稿件来影响客户选择的例子，本 Skill 不采用。设计论证应来自实际信息关系和可读性。
