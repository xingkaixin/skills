# Unslop 中文版

编辑中文文本，去除 AI 痕迹。先扫描下列模式，再改写。保留原意，贴合预期语气。

中文标准排版使用弯引号（“”与「」）和全角标点。不要按英文排版规则把它们“改正”成直引号或半角。

## 内容

1. **空泛归因。**「专家认为」「业内人士表示」「有观点认为」「相关报告显示」。指名来源，或删掉这句。
2. **没有数字的「数据感」。**「大幅提升」「显著改善」「成倍增长」后面没有数字。给出测量值，或删掉形容词。

## 语言

3. **AI 写作腔动词。** 深入探讨、深度解析、全面剖析、揭示、彰显、诠释、演绎、勾勒、见证、注入、激发、释放、打造、助力、护航、加持、聚焦、深耕、布局、发力、重塑、引领。多数句子删掉它们不损语义；剩下的换成「做、写、改、用、加」这类具体动词。
4. **商业黑话。** 赋能、抓手、闭环、底层逻辑、生态、护城河、飞轮、北极星指标、组合拳、方法论、心智、势能、颗粒度、拉通、沉淀、第二曲线。换成具体的名字：哪个文件，哪个函数。
5. **「不仅是 X，更是 Y」。** 及变体「不是 X，而是 Y」「既……又……更……」。直接说要的那个。
6. **强迫三连。** 排比是合法修辞；AI 的问题是每一组都凑满三个。用自然数量，两个就两个，五个就五个。
7. **假范围。**「从微服务到前端，从数据库到网关」，X 和 Y 不在同一把尺上。直接列对象。
8. **同义词轮换。**「该项目 / 此项目 / 这一方案 / 这套工具」指同一个东西。选一个称呼，重复用。中文接受重复。

## 标点与排版

9. **破折号限频。**「——」是合法中文标点。一段最多一处，多数段落应该没有。解释性内容用逗号，或另起一句。
10. **冒号当连接符。** 冒号用于引出列表或例子。「如果你要从旧版本迁移：先备份数据」中间的冒号删掉后句子照样成立，重写成不需要它。
11. **加粗滥用。** 不是每个术语、产品名、章节名都要加粗。
12. **「标签：」伪列表。** 特征是加粗标签 + 冒号 + 复述本行（「性能：性能提升了 30%」）。改成自然段。加粗引导句以句号结尾、其后是真正的新信息（「配置即类型。表定义和 TS 类型同住一个文件。」），不算。
13. **标题装饰 emoji。** 删。
14. **中英标点混排。** 中文句子用全角标点（，。：；？！），不与半角混用。弯引号是中文标准，保留。

## 对话痕迹

15. **聊天机器人腔。**「希望这对你有帮助」「如有问题随时问我」「当然可以！」「好的，」「让我来为你」。删。
16. **谄媚开场。**「好问题！」「你说得非常对！」直接回答。

## 填充与套话

17. **开头套话。**「在当今快速发展的时代」「随着……的不断发展」「近年来，……备受关注」「众所周知」。第一句直接说事实。
18. **空洞总结与结尾。**「综上所述」「总而言之」引出的空泛段，以及「未来可期」「让我们拭目以待」「……才刚刚开始」。给具体的下一步，或整段删掉。
19. **填充短语。**「为了能够」改「为了」；「由于……的原因」改「因为」；「值得一提的是」「需要注意的是」「在这个过程中」「不可否认」，删。
20. **过度对冲。**「可能在一定程度上或许」改「可能」。删掉「在一定程度上」句意不变的，删。

## 欧化语法

21. **「进行 / 作出 / 予以 / 加以 + 名词化动词」。**「对代码进行审查」改「审查代码」；「作出改善」改「改善」；「对需求予以满足」改「满足需求」。
22. **长定语前置。** 连环「的」超过两层：「这是一个能够帮助开发者快速构建高性能应用的框架」。拆句：「这个框架帮开发者快速构建高性能应用」。
23. **被字句滥用。**「被广泛应用于」「被认为是」「被称为」。说施动者：「开发者广泛用它」「社区普遍认为」。施动者确实未知或无关时，被动可以留。
24. **弱判断句。**「这是非常重要的」「这是很有意义的一件事」。重要在哪，给事实。

## 平实表达

25. **说机制，不说感觉。**「上手非常简单」「让开发更轻松」是感觉；「npm run dev 后打开 localhost:3003，改动立刻生效」是机制。检验：这句话能否原样出现在另一个项目的文档里？能，说明它没说任何关于本项目的东西，删。
26. **一句一意。** 读者需要回读才能解析的句子，拆开或删从句。
27. **副词垫场。**「显著提升」，提升多少；「极大地改善」，改善了什么。副词撑着弱动词，说明动词选错了。
28. **花哨词换平实词。**「利用」「借助」改「用」；「旨在」改「为了」；「致力于」删，或直说在做的事；「众多」改「很多」。
29. **文艺腔。** 有平实说法时的格言（「工欲善其事，必先利其器」）、拟人（「代码守住了底线」）、修辞性反问（「这难道不值得深思吗？」）。直接说。
30. **过度压缩。** 电报体、无主句、「A→B→C」符号链。写完整句子，主谓宾齐全，展开箭头和缩写。

## 输出

输出改写后的全文。被要求时，附上命中清单：规则编号 + 原句片段。默认不解释。
